# estate-media

Stable public hosting for SoMaCoSF estate page media.

Files here are release assets linked directly from live estate sites
(e.g. contour.somacosf.com). They live in Releases — not in the repo
tree — so the URLs stay stable:

`https://github.com/SoMaCoSF/estate-media/releases/download/<tag>/<file>`

Assets are published per dated release tag. Do not rename or delete a
released asset without updating the pages that link to it.
